# AnnChloe Storefront

앤클로이(`ann-chloe-storefront`) Next.js App Router 스토어프론트입니다. 지금은 `lib/products.js`와 `public/` 이미지로 돌아가는 **UI 카탈로그**입니다.

- 라이브: https://shopping-mall-xi-lyart.vercel.app/
- 로컬: `npm install` 후 `npm run dev`

장바구니·DB·한국 결제(Toss)까지 붙이는 순서는 아래 튜토리얼을 따르세요.

**[docs/ecommerce-tutorial.md](docs/ecommerce-tutorial.md)** — UI-only에서 실제 주문까지
